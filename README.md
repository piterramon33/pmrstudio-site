# PMR Studio — sitio web

Sitio estático (HTML, CSS y JavaScript, sin build) de PMR Studio, publicado en https://pmrstudio.site.
Copia de https://pmr-studio.com.

## Estructura
- `index.html`: página principal (ES/EN/IT; los textos están en `assets/js/main.js`)
- `legal/`: privacidad y términos
- `assets/`: estilos, scripts e imágenes
- `docs/portfolio/`: PDFs y vistas previas del portafolio

## Publicar
Comprimir el contenido de la carpeta en un .zip y subirlo a la raíz pública (`public_html`) de pmrstudio.site en Hostinger.
